## Terminal and resource semantics

The `(0,0)` quality cells are **not observed incorrect task outcomes**. They
are unavailable performance outcomes because every episode stopped
`incomplete` after resource exhaustion without an answer evaluation. The
quality discordance/dependence nuisance is therefore unidentifiable from this
calibration; no latent success was inferred.

Each final persisted resource state has provider interactions 4/4 and tool
attempts 4/4 exhausted. Reasoning remains below 8 (Adaptive 0, Fixed 4 or 5)
and decision cycles are 4/8. Provider and tool exhaustion coincide in the
terminal action sequence, so persistence cannot rank them as a strict temporal
first binder. The next canonical loop checks provider admission first and
blocks before another operation, physical attempt, transport, or charge.
Thus the shared finite provider/tool ceiling is a boundary censoring mechanism,
not evidence of unobserved resource demand beyond the boundary.

The current record schema does not persist a full final public runtime state,
answer status, or hypothetical legal next proposal. It supports only the
observed conclusion: continued execution would have required another admitted
provider operation, which the frozen guard rejected. No hypothetical provider
output is imputed.
